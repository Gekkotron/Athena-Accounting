# Loans Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `/loans` page that tracks several loans (and saved what-if simulations), each with multiple periods, computes the missing payment or end date, and shows capital owed today and the total cost (interest + insurance + fees + penalties).

**Architecture:** A pure, dependency-free TypeScript engine in `backend/src/domain/loans/engine/` turns a loan's inputs into a month-by-month schedule and a summary. The backend stores only inputs (`loans` table, jsonb periods) and runs the engine on every read/write; `POST /api/loans/simulate` serves the live preview. The frontend demo build imports the same engine file directly, so demo and server can never disagree.

**Tech Stack:** Fastify v5, Drizzle 0.36, zod 3, Postgres/PGlite; React 18, @tanstack/react-query 5, react-i18next, Tailwind; Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-16-loans-design.md`

```ts
import { describe, it, expect } from 'vitest';
import { buildSchedule, type LoanTerms, type LoanResult, type ScheduleRow } from '../src/domain/loans/engine/index.js';
import { annuity, fromCents, toCents } from '../src/domain/loans/engine/money.js';
import { instalmentDate } from '../src/domain/loans/engine/dates.js';

const ASOF = '2026-10-16';

function terms(over: Partial<LoanTerms> = {}): LoanTerms {
  return {
    principal: '200000.00',
    startDate: '2026-02-05',
    annualRate: '3.5',
    insuranceRate: '0',
    insuranceBasis: 'initial',
    fees: '0',
    periods: [],
    finalPeriod: { solve: 'payment', endDate: '2046-01' }, // 240 instalments
    earlyRepayments: [],
    ...over,
  };
}

function ok(res: LoanResult) {
  if (!res.ok) throw new Error(`expected ok, got ${JSON.stringify(res.errors)}`);
  return res;
}

const cents = (rows: ScheduleRow[], k: keyof ScheduleRow) =>
  rows.reduce((s, r) => s + toCents((r[k] as string | null) ?? '0'), 0);

// Invariants every valid schedule must satisfy.
function checkInvariants(t: LoanTerms, res: ReturnType<typeof ok>) {
  const rows = res.schedule;
  expect(rows[rows.length - 1]!.balance).toBe('0.00');
  // Σ capital + Σ early repayments = principal (capitalised interest is a
  // negative capital row, so it is already netted in Σ capital).
  expect(cents(rows, 'capital') + cents(rows, 'earlyRepayment')).toBe(toCents(t.principal));
  const s = res.summary.totals;
  expect(toCents(s.cost)).toBe(
    toCents(s.interest) + toCents(s.insurance) + toCents(s.fees) + toCents(s.penalties),
  );
  expect(toCents(s.totalPaid)).toBe(toCents(t.principal) + toCents(s.cost));
  rows.forEach((r, i) => expect(r.index).toBe(i + 1));
}

describe('money + dates helpers', () => {
  it('round-trips cents', () => {
    expect(toCents('0.29')).toBe(29);
    expect(fromCents(123456)).toBe('1234.56');
    expect(fromCents(-5)).toBe('-0.05');
  });
  it('clamps the 31st to the month end', () => {
    expect(instalmentDate('2026-01-31', 1)).toBe('2026-02-28');
    expect(instalmentDate('2028-01-31', 1)).toBe('2028-02-29');
    expect(instalmentDate('2026-01-31', 2)).toBe('2026-03-31');
    expect(instalmentDate('2026-11-15', 2)).toBe('2027-01-15');
  });
});

describe('constant loan', () => {
  it('200 000 € at 3.5 % over 240 months → 1 159.92 €/month', () => {
    const t = terms();
    const res = ok(buildSchedule(t, ASOF));
    expect(res.schedule).toHaveLength(240);
    expect(res.summary.solvedPayment).toBe('1159.92');
    expect(res.summary.endDate).toBe('2046-01-05');
    checkInvariants(t, res);
  });

  it('0 % consumer loan splits the capital evenly', () => {
    const t = terms({ principal: '1200', annualRate: '0', finalPeriod: { solve: 'payment', endDate: '2027-01' } });
    const res = ok(buildSchedule(t, ASOF));
    expect(res.schedule).toHaveLength(12);
    expect(res.schedule.every((r) => r.payment === '100.00' && r.interest === '0.00')).toBe(true);
    expect(res.summary.totals.cost).toBe('0.00');
    checkInvariants(t, res);
  });

  it('a one-month loan pays everything at once', () => {
    const t = terms({ principal: '1000', annualRate: '12', finalPeriod: { solve: 'payment', endDate: '2026-02' } });
    const res = ok(buildSchedule(t, ASOF));
    expect(res.schedule).toHaveLength(1);
    expect(res.schedule[0]!.payment).toBe('1010.00');
    checkInvariants(t, res);
  });
});

describe('reduced first period (palier)', () => {
  it('24 × 800 € then the solved payment matches the closed form', () => {
    const t = terms({ periods: [{ kind: 'payment', months: 24, amount: '800' }] });
    const res = ok(buildSchedule(t, ASOF));
    const r = 0.035 / 12;
    const g = Math.pow(1 + r, 24);
    const b24 = 200000 * g - (800 * (g - 1)) / r;
    const expected = (b24 * r) / (1 - Math.pow(1 + r, -216));
    expect(Math.abs(Number(res.summary.solvedPayment) - expected)).toBeLessThan(0.05);
    expect(Number(res.summary.solvedPayment)).toBeGreaterThan(1215);
    expect(res.schedule).toHaveLength(240);
    checkInvariants(t, res);
  });
});

describe('solve modes round-trip', () => {
  it('feeding the solved payment back gives the same end date', () => {
    const solved = ok(buildSchedule(terms(), ASOF));
    const back = ok(buildSchedule(
      terms({ finalPeriod: { solve: 'end_date', amount: solved.summary.solvedPayment! } }),
      ASOF,
    ));
    expect(back.summary.endDate).toBe(solved.summary.endDate);
    checkInvariants(terms(), back);
  });

  it('a higher amount moves the end date earlier', () => {
    const t = terms({ finalPeriod: { solve: 'end_date', amount: '1400' } });
    const res = ok(buildSchedule(t, ASOF));
    expect(res.summary.endDate < '2046-01-05').toBe(true);
    expect(res.summary.solvedPayment).toBe('1400.00');
    checkInvariants(t, res);
  });
});

describe('insurance', () => {
  it('initial basis is constant', () => {
    const t = terms({ insuranceRate: '0.30', insuranceBasis: 'initial' });
    const res = ok(buildSchedule(t, ASOF));
    expect(res.schedule.every((r) => r.insurance === '50.00')).toBe(true);
    expect(res.summary.totals.insurance).toBe('12000.00');
    expect(res.summary.currentPaymentWithInsurance).toBe('1209.92');
    checkInvariants(t, res);
  });

  it('remaining basis decreases with the capital owed', () => {
    const t = terms({ insuranceRate: '0.30', insuranceBasis: 'remaining' });
    const res = ok(buildSchedule(t, ASOF));
    expect(res.schedule[0]!.insurance).toBe('50.00');
    expect(Number(res.schedule[239]!.insurance)).toBeLessThan(1);
    expect(Number(res.summary.totals.insurance)).toBeLessThan(12000);
    checkInvariants(t, res);
  });
});

describe('deferrals', () => {
  it('partial deferral pays interest only, capital unchanged', () => {
    const t = terms({ periods: [{ kind: 'partial_deferral', months: 12 }] });
    const res = ok(buildSchedule(t, ASOF));
    const first = res.schedule.slice(0, 12);
    expect(first.every((r) => r.capital === '0.00' && r.balance === '200000.00')).toBe(true);
    expect(first[0]!.payment).toBe('583.33');
    expect(res.schedule).toHaveLength(240);
    checkInvariants(t, res);
  });

  it('total deferral capitalises interest, insurance still due', () => {
    const t = terms({
      insuranceRate: '0.30',
      periods: [{ kind: 'total_deferral', months: 6 }],
    });
    const res = ok(buildSchedule(t, ASOF));
    const first = res.schedule.slice(0, 6);
    expect(first.every((r) => r.payment === '0.00' && r.insurance === '50.00')).toBe(true);
    expect(Number(first[5]!.balance)).toBeGreaterThan(203000);
    checkInvariants(t, res);
  });
});

describe('rate per period', () => {
  it('uses the override for its period and the loan rate after', () => {
    const t = terms({ periods: [{ kind: 'payment', months: 12, amount: '1000', rate: '1' }] });
    const res = ok(buildSchedule(t, ASOF));
    expect(res.schedule[0]!.interest).toBe('166.67');
    expect(res.schedule[0]!.rate).toBe('1');
    expect(res.schedule[12]!.rate).toBe('3.5');
    checkInvariants(t, res);
  });
});

describe('early repayment', () => {
  const base = ok(buildSchedule(terms(), ASOF));

  it('reduce_payment keeps the end date and lowers the payment', () => {
    const t = terms({ earlyRepayments: [{ date: '2030-01', amount: '20000', effect: 'reduce_payment' }] });
    const res = ok(buildSchedule(t, ASOF));
    expect(res.summary.endDate).toBe(base.summary.endDate);
    const after = res.schedule.find((r) => r.date > '2030-01-31')!;
    expect(Number(after.payment)).toBeLessThan(1159.92);
    expect(Number(res.summary.totals.interest)).toBeLessThan(Number(base.summary.totals.interest));
    checkInvariants(t, res);
  });

  it('shorten keeps the payment and ends earlier', () => {
    const t = terms({ earlyRepayments: [{ date: '2030-01', amount: '20000', effect: 'shorten', penalty: '600' }] });
    const res = ok(buildSchedule(t, ASOF));
    expect(res.summary.endDate < base.summary.endDate).toBe(true);
    const after = res.schedule.find((r) => r.date > '2030-01-31')!;
    expect(after.payment).toBe('1159.92');
    expect(res.summary.totals.penalties).toBe('600.00');
    checkInvariants(t, res);
  });

  it('a full payoff ends the loan on that month', () => {
    const t = terms({ earlyRepayments: [{ date: '2027-01', amount: '999999', effect: 'shorten' }] });
    const res = ok(buildSchedule(t, ASOF));
    expect(res.summary.endDate).toBe('2027-01-05');
    checkInvariants(t, res);
  });

  it('inside a fixed period with reduce_payment, the end date holds', () => {
    const t = terms({
      periods: [{ kind: 'payment', months: 24, amount: '800' }],
      finalPeriod: { solve: 'end_date', amount: '1300' },
      earlyRepayments: [{ date: '2027-01', amount: '10000', effect: 'reduce_payment' }],
    });
    const ref = ok(buildSchedule({ ...t, earlyRepayments: [] }, ASOF));
    const res = ok(buildSchedule(t, ASOF));
    expect(res.summary.endDate).toBe(ref.summary.endDate);
    expect(Number(res.summary.solvedPayment)).toBeLessThan(1300);
    checkInvariants(t, res);
  });

  it('inside a fixed period with shorten, the payment holds', () => {
    const t = terms({
      periods: [{ kind: 'payment', months: 24, amount: '800' }],
      earlyRepayments: [{ date: '2027-01', amount: '10000', effect: 'shorten' }],
    });
    const ref = ok(buildSchedule({ ...t, earlyRepayments: [] }, ASOF));
    const res = ok(buildSchedule(t, ASOF));
    expect(res.summary.solvedPayment).toBe(ref.summary.solvedPayment);
    expect(res.summary.endDate < ref.summary.endDate).toBe(true);
    checkInvariants(t, res);
  });
});
```

```ts
// Loan engine contracts. Pure data — no Node, DB or framework types — so the
// frontend demo build can import this module directly. Mirrored (by hand)
// in shared/api-contracts.ts for the frontend's API types.

export const MAX_INSTALMENTS = 600;

export type InsuranceBasis = 'initial' | 'remaining';
export type FixedPeriodKind = 'payment' | 'partial_deferral' | 'total_deferral';
export type RepaymentEffect = 'reduce_payment' | 'shorten';

export interface FixedPeriod {
  kind: FixedPeriodKind;
  months: number;
  amount?: string; // required iff kind === 'payment'; excludes insurance
  rate?: string | null; // annual % override for this period
}

export type FinalPeriod =
  | { solve: 'payment'; endDate: string; rate?: string | null } // endDate: YYYY-MM
  | { solve: 'end_date'; amount: string; rate?: string | null };

export interface EarlyRepayment {
  date: string; // YYYY-MM — applied right after that month's instalment
  amount: string;
  effect: RepaymentEffect;
  penalty?: string;
}

export interface LoanTerms {
  principal: string;
  startDate: string; // YYYY-MM-DD, first instalment
  annualRate: string; // nominal annual %, "3.5" = 3.5 %
  insuranceRate: string; // annual %
  insuranceBasis: InsuranceBasis;
  fees: string;
  periods: FixedPeriod[];
  finalPeriod: FinalPeriod;
  earlyRepayments: EarlyRepayment[];
}

export type RowKind = FixedPeriodKind | 'final';

export interface ScheduleRow {
  index: number; // 1-based
  date: string; // YYYY-MM-DD
  periodIndex: number; // index into periods, -1 = final period
  kind: RowKind;
  rate: string;
  payment: string; // instalment excl. insurance
  interest: string;
  capital: string; // negative during a total deferral
  insurance: string;
  earlyRepayment: string | null;
  balance: string; // capital owed after this month
}

export type LoanErrorCode =
  | 'invalid_principal'
  | 'invalid_rate'
  | 'invalid_amount'
  | 'invalid_months'
  | 'invalid_date'
  | 'missing_amount'
  | 'end_before_fixed_periods'
  | 'payment_too_low'
  | 'too_long'
  | 'early_repayment_before_start'
  | 'early_repayment_after_end';

export interface LoanError {
  code: LoanErrorCode;
  field?: string; // dotted path into LoanTerms, e.g. "periods.1.amount"
}

export type LoanWarningCode = 'repaid_during_fixed_period' | 'negative_amortization';

export interface LoanWarning {
  code: LoanWarningCode;
  field?: string;
}

export type LoanStatus = 'not_started' | 'active' | 'repaid';

export interface LoanSummary {
  currentPayment: string;
  currentPaymentWithInsurance: string;
  solvedPayment: string | null;
  endDate: string;
  durationMonths: number;
  totals: {
    interest: string;
    insurance: string;
    fees: string;
    penalties: string;
    cost: string; // interest + insurance + fees + penalties
    totalPaid: string; // principal + cost
  };
  today: {
    asOf: string;
    capitalOwed: string;
    repaidPct: number;
    interestPaid: string;
    monthsLeft: number;
    nextInstalment: { date: string; amount: string } | null; // amount incl. insurance
    status: LoanStatus;
  };
}

export type LoanResult =
  | { ok: true; schedule: ScheduleRow[]; summary: LoanSummary; warnings: LoanWarning[] }
  | { ok: false; errors: LoanError[] };
```

```ts
// Integer-cent arithmetic for the loan engine. Every amount is converted to
// cents on the way in and back to a "1234.56" string on the way out, so 600
// months of per-month rounding can't drift.

export function roundHalfAway(x: number): number {
  return x < 0 ? -Math.round(-x) : Math.round(x);
}

export function toCents(s: string): number {
  return roundHalfAway(Number(s) * 100);
}

export function fromCents(c: number): string {
  const sign = c < 0 ? '-' : '';
  const a = Math.abs(c);
  return `${sign}${Math.floor(a / 100)}.${String(a % 100).padStart(2, '0')}`;
}

// Nominal annual % → monthly rate (taux proportionnel, what French banks use).
export function monthlyRate(annualPct: string): number {
  return Number(annualPct) / 100 / 12;
}

// Constant instalment (cents) repaying `balance` over `n` months at monthly
// rate `r`. Rounded UP to the cent so the loan always finishes within `n`
// months; the last instalment absorbs the difference.
export function annuity(balance: number, r: number, n: number): number {
  if (n <= 0) return balance;
  if (r === 0) return Math.ceil(balance / n);
  return Math.ceil((balance * r) / (1 - Math.pow(1 + r, -n)) - 1e-9);
}

// Months needed to repay `balance` with instalment `payment` (cents), stepping
// with the same per-month rounding as the schedule. null = never repaid.
export function monthsToRepay(balance: number, r: number, payment: number, cap: number): number | null {
  let b = balance;
  for (let n = 1; n <= cap; n++) {
    const interest = roundHalfAway(b * r);
    const capital = payment - interest;
    if (capital <= 0) return null;
    if (capital >= b) return n;
    b -= capital;
  }
  return null;
}
```

```ts
// Month arithmetic on ISO strings. No Date objects for the calendar maths —
// only to find a month's last day — so time zones can't shift a date.

const ISO_DATE = /^\d{4}-(0[1-9]|1[0-2])-(0[1-9]|[12]\d|3[01])$/;
const YEAR_MONTH = /^\d{4}-(0[1-9]|1[0-2])$/;

export function isIsoDate(s: unknown): s is string {
  return typeof s === 'string' && ISO_DATE.test(s);
}

export function isYearMonth(s: unknown): s is string {
  return typeof s === 'string' && YEAR_MONTH.test(s);
}

// Absolute month number for "YYYY-MM" or "YYYY-MM-DD".
export function monthIndex(s: string): number {
  return Number(s.slice(0, 4)) * 12 + (Number(s.slice(5, 7)) - 1);
}

const pad = (n: number) => String(n).padStart(2, '0');

// Date of the instalment `k` months after `startDate` (k = 0 → startDate),
// keeping the day of month and clamping to the month's last day.
export function instalmentDate(startDate: string, k: number): string {
  const idx = monthIndex(startDate) + k;
  const y = Math.floor(idx / 12);
  const m = (idx % 12) + 1;
  const lastDay = new Date(Date.UTC(y, m, 0)).getUTCDate();
  const day = Math.min(Number(startDate.slice(8, 10)), lastDay);
  return `${y}-${pad(m)}-${pad(day)}`;
}
```

```ts
import { isIsoDate, isYearMonth } from './dates.js';
import { MAX_INSTALMENTS, type LoanError, type LoanTerms } from './types.js';

const DECIMAL = /^\d+(\.\d+)?$/;
const isDecimal = (s: unknown): s is string => typeof s === 'string' && DECIMAL.test(s);

// Shape-level checks the engine needs before it can run. The HTTP layer's
// zod schema catches most of these first; the engine re-checks so the demo
// build (no zod) and future callers get the same guarantees.
export function validateTerms(t: LoanTerms): LoanError[] {
  const errors: LoanError[] = [];
  const rate = (v: unknown, field: string) => {
    if (!isDecimal(v) || Number(v) > 100) errors.push({ code: 'invalid_rate', field });
  };
  const amount = (v: unknown, field: string, code: LoanError['code'] = 'invalid_amount') => {
    if (!isDecimal(v) || Number(v) <= 0) errors.push({ code, field });
  };

  if (!isDecimal(t.principal) || Number(t.principal) <= 0) {
    errors.push({ code: 'invalid_principal', field: 'principal' });
  }
  if (!isIsoDate(t.startDate)) errors.push({ code: 'invalid_date', field: 'startDate' });
  rate(t.annualRate, 'annualRate');
  rate(t.insuranceRate, 'insuranceRate');
  if (!isDecimal(t.fees)) errors.push({ code: 'invalid_amount', field: 'fees' });

  let months = 0;
  t.periods.forEach((p, i) => {
    if (!Number.isInteger(p.months) || p.months < 1) {
      errors.push({ code: 'invalid_months', field: `periods.${i}.months` });
    } else {
      months += p.months;
    }
    if (p.kind === 'payment') amount(p.amount, `periods.${i}.amount`, 'missing_amount');
    if (p.rate != null) rate(p.rate, `periods.${i}.rate`);
  });
  if (months > MAX_INSTALMENTS) errors.push({ code: 'too_long', field: 'periods' });

  const fp = t.finalPeriod;
  if (fp.solve === 'payment') {
    if (!isYearMonth(fp.endDate)) errors.push({ code: 'invalid_date', field: 'finalPeriod.endDate' });
  } else {
    amount(fp.amount, 'finalPeriod.amount', 'missing_amount');
  }
  if (fp.rate != null) rate(fp.rate, 'finalPeriod.rate');

  t.earlyRepayments.forEach((er, i) => {
    if (!isYearMonth(er.date)) errors.push({ code: 'invalid_date', field: `earlyRepayments.${i}.date` });
    amount(er.amount, `earlyRepayments.${i}.amount`);
    if (er.penalty != null && !isDecimal(er.penalty)) {
      errors.push({ code: 'invalid_amount', field: `earlyRepayments.${i}.penalty` });
    }
  });
  return errors;
}
```

```ts
import { instalmentDate, monthIndex } from './dates.js';
import { annuity, fromCents, monthlyRate, monthsToRepay, roundHalfAway, toCents } from './money.js';
import {
  MAX_INSTALMENTS,
  type LoanError,
  type LoanTerms,
  type LoanWarning,
  type RepaymentEffect,
  type RowKind,
  type ScheduleRow,
} from './types.js';

// Mutable walk state. Amounts in cents.
interface Cursor {
  rows: ScheduleRow[];
  balance: number; // capital owed after the last pushed row
  penalties: number;
  lastEffect: RepaymentEffect | null; // effect of the latest applied early repayment
  applied: Set<number>; // indexes into terms.earlyRepayments
  warnings: LoanWarning[];
}

interface Month {
  periodIndex: number;
  kind: RowKind;
  ratePct: string;
  payment: number;
  interest: number;
  capital: number;
}

export interface RowsResult {
  rows: ScheduleRow[];
  warnings: LoanWarning[];
  penalties: number;
  solvedPayment: number | null; // first instalment of the final period
}

function warn(c: Cursor, code: LoanWarning['code'], field: string): void {
  if (!c.warnings.some((w) => w.code === code && w.field === field)) c.warnings.push({ code, field });
}

function insuranceCents(t: LoanTerms, balance: number): number {
  const r = monthlyRate(t.insuranceRate);
  return roundHalfAway((t.insuranceBasis === 'initial' ? toCents(t.principal) : balance) * r);
}

// Pushes one instalment, then applies that month's early repayments.
// Returns the early-repayment cents applied this month.
function pushRow(t: LoanTerms, c: Cursor, m: Month, withEarly: boolean): number {
  const index = c.rows.length;
  const date = instalmentDate(t.startDate, index);
  const insurance = insuranceCents(t, c.balance);
  c.balance -= m.capital;
  let early = 0;
  if (withEarly) {
    const month = monthIndex(date);
    t.earlyRepayments.forEach((er, i) => {
      if (c.applied.has(i) || monthIndex(er.date) !== month || c.balance <= 0) return;
      const amt = Math.min(toCents(er.amount), c.balance);
      c.balance -= amt;
      early += amt;
      c.penalties += er.penalty ? toCents(er.penalty) : 0;
      c.lastEffect = er.effect;
      c.applied.add(i);
    });
  }
  c.rows.push({
    index: index + 1,
    date,
    periodIndex: m.periodIndex,
    kind: m.kind,
    rate: m.ratePct,
    payment: fromCents(m.payment),
    interest: fromCents(m.interest),
    capital: fromCents(m.capital),
    insurance: fromCents(insurance),
    earlyRepayment: early > 0 ? fromCents(early) : null,
    balance: fromCents(c.balance),
  });
  return early;
}

function runFixed(t: LoanTerms, withEarly: boolean): Cursor {
  const c: Cursor = {
    rows: [], balance: toCents(t.principal), penalties: 0,
    lastEffect: null, applied: new Set(), warnings: [],
  };
  t.periods.forEach((p, pi) => {
    const ratePct = p.rate ?? t.annualRate;
    const r = monthlyRate(ratePct);
    for (let m = 0; m < p.months && c.balance > 0; m++) {
      const interest = roundHalfAway(c.balance * r);
      let payment = 0;
      let capital = -interest; // total_deferral: interest is capitalised
      if (p.kind === 'partial_deferral') {
        payment = interest;
        capital = 0;
      } else if (p.kind === 'payment') {
        payment = toCents(p.amount ?? '0');
        capital = payment - interest;
        if (capital < 0) warn(c, 'negative_amortization', `periods.${pi}.amount`);
        if (capital >= c.balance) {
          capital = c.balance;
          payment = c.balance + interest;
          warn(c, 'repaid_during_fixed_period', `periods.${pi}`);
        }
      }
      pushRow(t, c, { periodIndex: pi, kind: p.kind, ratePct, payment, interest, capital }, withEarly);
    }
  });
  return c;
}

// Walks the final period. `endIdx` is the 0-based index of the last
// instalment when the end date is pinned, null when it floats.
function runFinal(t: LoanTerms, c: Cursor): LoanError | number {
  const fp = t.finalPeriod;
  const ratePct = fp.rate ?? t.annualRate;
  const r = monthlyRate(ratePct);
  const k0 = c.rows.length;
  // Early repayments inside fixed periods: the latest one's effect decides
  // what the final period keeps (spec: "most recent one decides").
  const fixedEffect = c.lastEffect;
  let payment: number;
  let endIdx: number | null = null;

  if (fp.solve === 'payment') {
    const n = monthIndex(fp.endDate) - monthIndex(instalmentDate(t.startDate, k0)) + 1;
    if (fixedEffect === 'shorten') {
      payment = annuity(runFixed(t, false).balance, r, n);
    } else {
      payment = annuity(c.balance, r, n);
      endIdx = k0 + n - 1;
    }
  } else {
    payment = toCents(fp.amount);
    if (fixedEffect === 'reduce_payment') {
      const nRef = monthsToRepay(runFixed(t, false).balance, r, payment, MAX_INSTALMENTS);
      if (nRef === null) return { code: 'payment_too_low', field: 'finalPeriod.amount' };
      endIdx = k0 + nRef - 1;
      payment = annuity(c.balance, r, nRef);
    }
  }
  if (payment <= roundHalfAway(c.balance * r)) {
    return { code: 'payment_too_low', field: fp.solve === 'end_date' ? 'finalPeriod.amount' : 'finalPeriod.endDate' };
  }
  const solved = payment;

  while (c.balance > 0) {
    const index = c.rows.length;
    if (index >= MAX_INSTALMENTS) return { code: 'too_long', field: 'finalPeriod' };
    const interest = roundHalfAway(c.balance * r);
    let pay = payment;
    let capital = pay - interest;
    if ((endIdx !== null && index >= endIdx) || capital >= c.balance) {
      capital = c.balance;
      pay = c.balance + interest;
    }
    const early = pushRow(t, c, { periodIndex: -1, kind: 'final', ratePct, payment: pay, interest, capital }, true);
    if (early === 0 || c.balance <= 0) continue;
    if (c.lastEffect === 'shorten') {
      endIdx = null;
    } else {
      if (endIdx === null) {
        const left = monthsToRepay(c.balance + early, r, payment, MAX_INSTALMENTS);
        endIdx = index + (left ?? 1);
      }
      payment = annuity(c.balance, r, Math.max(endIdx - index, 1));
    }
  }
  return solved;
}

export function buildRows(t: LoanTerms): RowsResult | { errors: LoanError[] } {
  const fixedMonths = t.periods.reduce((s, p) => s + p.months, 0);
  const fp = t.finalPeriod;
  if (fp.solve === 'payment'
    && monthIndex(fp.endDate) < monthIndex(instalmentDate(t.startDate, fixedMonths))) {
    return { errors: [{ code: 'end_before_fixed_periods', field: 'finalPeriod.endDate' }] };
  }

  const c = runFixed(t, true);
  let solvedPayment: number | null = null;
  if (c.balance > 0) {
    const res = runFinal(t, c);
    if (typeof res !== 'number') return { errors: [res] };
    solvedPayment = res;
  }

  const errors: LoanError[] = [];
  t.earlyRepayments.forEach((er, i) => {
    if (c.applied.has(i)) return;
    const before = monthIndex(er.date) < monthIndex(t.startDate);
    errors.push({
      code: before ? 'early_repayment_before_start' : 'early_repayment_after_end',
      field: `earlyRepayments.${i}.date`,
    });
  });
  if (errors.length > 0) return { errors };

  return { rows: c.rows, warnings: c.warnings, penalties: c.penalties, solvedPayment };
}
```

```ts
import { fromCents, toCents } from './money.js';
import type { LoanSummary, LoanTerms, ScheduleRow } from './types.js';

const sum = (rows: ScheduleRow[], pick: (r: ScheduleRow) => string | null) =>
  rows.reduce((s, r) => s + toCents(pick(r) ?? '0'), 0);

// Totals over the whole schedule plus the "where am I on `asOf`" block.
// An instalment dated on or before `asOf` counts as paid.
export function summarize(
  t: LoanTerms,
  rows: ScheduleRow[],
  penalties: number,
  solvedPayment: number | null,
  asOf: string,
): LoanSummary {
  const principal = toCents(t.principal);
  const interest = sum(rows, (r) => r.interest);
  const insurance = sum(rows, (r) => r.insurance);
  const fees = toCents(t.fees);
  const cost = interest + insurance + fees + penalties;

  const paid = rows.filter((r) => r.date <= asOf);
  const next = rows[paid.length] ?? null;
  const last = rows[rows.length - 1];
  const owed = paid.length > 0 ? toCents(paid[paid.length - 1]!.balance) : principal;
  const status = paid.length === 0 ? 'not_started' : next === null ? 'repaid' : 'active';
  const current = next ?? null;
  const withInsurance = (r: ScheduleRow) => fromCents(toCents(r.payment) + toCents(r.insurance));

  return {
    currentPayment: current ? current.payment : '0.00',
    currentPaymentWithInsurance: current ? withInsurance(current) : '0.00',
    solvedPayment: solvedPayment === null ? null : fromCents(solvedPayment),
    endDate: last ? last.date : t.startDate,
    durationMonths: rows.length,
    totals: {
      interest: fromCents(interest),
      insurance: fromCents(insurance),
      fees: fromCents(fees),
      penalties: fromCents(penalties),
      cost: fromCents(cost),
      totalPaid: fromCents(principal + cost),
    },
    today: {
      asOf,
      capitalOwed: fromCents(owed),
      repaidPct: Math.min(100, Math.max(0, Math.round(((principal - owed) / principal) * 10000) / 100)),
      interestPaid: fromCents(sum(paid, (r) => r.interest)),
      monthsLeft: rows.length - paid.length,
      nextInstalment: next ? { date: next.date, amount: withInsurance(next) } : null,
      status,
    },
  };
}
```

```ts
// Parses and engine-checks a create/update body. Sends the 400/404/422
// reply itself and returns null when the request must stop there.
async function readBody(
  uid: number,
  raw: unknown,
  reply: FastifyReply,
  selfId: number | null,
): Promise<{ values: LoanBodyT; summary: LoanSummary } | null> {
  const parsed = LoanBody.safeParse(raw);
  if (!parsed.success) {
    reply.code(400).send({ error: 'invalid input', issues: parsed.error.issues });
    return null;
  }
  const values = parsed.data;
  if (values.sourceLoanId !== null) {
    if (values.sourceLoanId === selfId) {
      reply.code(400).send({ error: 'a loan cannot be its own source' });
      return null;
    }
    if (!(await loadOwn(uid, values.sourceLoanId))) {
      reply.code(404).send({ error: 'not found' });
      return null;
    }
  }
  const res = buildSchedule(toTerms(values), todayIso());
  if (!res.ok) {
    reply.code(422).send({ error: 'invalid loan', errors: res.errors });
    return null;
  }
  return { values, summary: res.summary };
}

export function registerCrud(app: FastifyInstance): void {
  app.post('/api/loans', async (req, reply) => {
    const uid = userId(req);
    const input = await readBody(uid, req.body, reply, null);
    if (!input) return reply;
    try {
      const [row] = await db.insert(loans).values({ userId: uid, ...input.values }).returning();
      if (!row) throw new Error('insert returned no row');
      return reply.code(201).send({ loan: toRecord(row), summary: input.summary });
    } catch (err) {
      if (isPgError(err) && err.code === '23505') return reply.code(409).send(NAME_TAKEN);
      throw err;
    }
  });

  app.get('/api/loans/:id', async (req, reply) => {
    const uid = userId(req);
    const id = parseId(req, reply);
    if (id === null) return;
    const q = AsOfQuery.safeParse(req.query);
    if (!q.success) return reply.code(400).send({ error: 'invalid input', issues: q.error.issues });
    const row = await loadOwn(uid, id);
    if (!row) return reply.code(404).send({ error: 'not found' });
    const loan = toRecord(row);
    const res = buildSchedule(toTerms(loan), q.data.asOf ?? todayIso());
    if (!res.ok) return { loan, schedule: [], summary: null, warnings: [], errors: res.errors };
    return { loan, schedule: res.schedule, summary: res.summary, warnings: res.warnings };
  });

  app.put('/api/loans/:id', async (req, reply) => {
    const uid = userId(req);
    const id = parseId(req, reply);
    if (id === null) return;
    // Ownership first so a cross-user PUT is a 404 even with a bad body.
    if (!(await loadOwn(uid, id))) return reply.code(404).send({ error: 'not found' });
    const input = await readBody(uid, req.body, reply, id);
    if (!input) return reply;
    try {
      const [row] = await db
        .update(loans)
        .set({ ...input.values, updatedAt: new Date() })
        .where(and(eq(loans.id, id), eq(loans.userId, uid)))
        .returning();
      if (!row) return reply.code(404).send({ error: 'not found' });
      return { loan: toRecord(row), summary: input.summary };
    } catch (err) {
      if (isPgError(err) && err.code === '23505') return reply.code(409).send(NAME_TAKEN);
      throw err;
    }
  });

  app.delete('/api/loans/:id', async (req, reply) => {
    const uid = userId(req);
    const id = parseId(req, reply);
    if (id === null) return;
    const [deleted] = await db
      .delete(loans)
      .where(and(eq(loans.id, id), eq(loans.userId, uid)))
      .returning({ id: loans.id });
    if (!deleted) return reply.code(404).send({ error: 'not found' });
    return { ok: true };
  });
}
```

```ts
import { and, eq } from 'drizzle-orm';
import { db } from '../../../db/client.js';
import { loans } from '../../../db/schema.js';
import type { BackupDump } from './schema.js';

type Tx = Parameters<Parameters<typeof db.transaction>[0]>[0];

// Two passes so the self-referencing FK can never trip on row order:
// insert every loan with source_loan_id NULL, then re-link simulations to
// their source by name. Returns the inserted count.
export async function restoreLoans(
  tx: Tx,
  uid: number,
  dumpLoans: NonNullable<BackupDump['loans']>,
): Promise<number> {
  if (dumpLoans.length === 0) return 0;
  const inserted = await tx
    .insert(loans)
    .values(dumpLoans.map((l) => {
      const { sourceLoan, ...rest } = l;
      void sourceLoan; // re-linked in the second pass below
      return { ...rest, userId: uid, sourceLoanId: null };
    }))
    .returning({ id: loans.id, name: loans.name });
  const idByName = new Map(inserted.map((r) => [r.name, r.id]));
  for (const l of dumpLoans) {
    if (l.sourceLoan === null) continue;
    const sourceId = idByName.get(l.sourceLoan);
    const selfId = idByName.get(l.name);
    if (sourceId === undefined || selfId === undefined) continue;
    await tx
      .update(loans)
      .set({ sourceLoanId: sourceId })
      .where(and(eq(loans.id, selfId), eq(loans.userId, uid)));
  }
  return inserted.length;
}
```

```ts
// Demo /api/loans*. Runs the REAL backend engine (pure module, bundled by
// Vite from outside frontend/src) so demo numbers match the server exactly.
import { buildSchedule, type LoanResult } from '../../../../../backend/src/domain/loans/engine/index';
import type { Loan, LoanInput, LoanTermsInput } from '../../../../../shared/api-contracts';
import { getState, setState } from '../store';
import { registerHandler, type DemoRequest } from '../index';
import { ApiError } from '../../apiError';
import { nextId } from './writes/lib';
import { todayLocalIso } from '../../../lib/dates';

const NAME_TAKEN = 'a loan with this name already exists';

// The seed's frozen "today" keeps the seeded progress stable.
function asOf(): string {
  const v = getState().settings.seedTodayForDemo;
  return typeof v === 'string' ? v : todayLocalIso();
}

function loansList(): Loan[] {
  return getState().loans ?? [];
}

function run(l: LoanTermsInput): LoanResult {
  return buildSchedule(
    {
      principal: l.principal,
      startDate: l.startDate,
      annualRate: l.annualRate,
      insuranceRate: l.insuranceRate,
      insuranceBasis: l.insuranceBasis,
      fees: l.fees,
      periods: l.periods,
      finalPeriod: l.finalPeriod,
      earlyRepayments: l.earlyRepayments,
    },
    asOf(),
  );
}

function notFound(): never {
  throw new ApiError('not found', 404, { error: 'not found' });
}

function loanOrThrow(id: number): Loan {
  return loansList().find((l) => l.id === id) ?? notFound();
}

function invalid(errors: unknown): never {
  throw new ApiError('invalid loan', 422, { error: 'invalid loan', errors });
}

function readInput(req: DemoRequest, selfId: number | null) {
  const b = (req.body ?? {}) as Partial<LoanInput>;
  if (typeof b.name !== 'string' || !b.name.trim() || !b.finalPeriod) {
    throw new ApiError('invalid input', 400, { error: 'invalid input' });
  }
  const input: LoanInput = {
    name: b.name.trim(),
    kind: b.kind ?? 'other',
    isSimulation: b.isSimulation ?? false,
    sourceLoanId: b.sourceLoanId ?? null,
    currency: b.currency ?? 'EUR',
    principal: b.principal ?? '',
    startDate: b.startDate ?? '',
    annualRate: b.annualRate ?? '',
    insuranceRate: b.insuranceRate ?? '0',
    insuranceBasis: b.insuranceBasis ?? 'initial',
    fees: b.fees ?? '0',
    periods: b.periods ?? [],
    finalPeriod: b.finalPeriod,
    earlyRepayments: b.earlyRepayments ?? [],
  };
  if (input.sourceLoanId !== null
    && (input.sourceLoanId === selfId || !loansList().some((l) => l.id === input.sourceLoanId))) {
    notFound();
  }
  if (loansList().some((l) => l.name === input.name && l.id !== selfId)) {
    throw new ApiError(NAME_TAKEN, 409, { error: NAME_TAKEN });
  }
  const res = run(input);
  if (!res.ok) invalid(res.errors);
  return { input, summary: res.summary };
}

function handleList() {
  return {
    loans: loansList().map((l) => {
      const res = run(l);
      return { ...l, summary: res.ok ? res.summary : null };
    }),
  };
}

function handleGet(req: DemoRequest) {
  const loan = loanOrThrow(Number(req.query.id));
  const res = run(loan);
  if (!res.ok) return { loan, schedule: [], summary: null, warnings: [], errors: res.errors };
  return { loan, schedule: res.schedule, summary: res.summary, warnings: res.warnings };
}

function handleCreate(req: DemoRequest) {
  const { input, summary } = readInput(req, null);
  const now = new Date().toISOString();
  let loan: Loan | null = null;
  setState((s) => {
    const list = (s.loans ??= []);
    loan = { ...input, id: nextId(list), createdAt: now, updatedAt: now };
    list.push(loan);
  });
  return { loan, summary };
}

function handleUpdate(req: DemoRequest) {
  const id = Number(req.query.id);
  const current = loanOrThrow(id);
  const { input, summary } = readInput(req, id);
  const loan: Loan = { ...input, id, createdAt: current.createdAt, updatedAt: new Date().toISOString() };
  setState((s) => {
    s.loans = (s.loans ?? []).map((l) => (l.id === id ? loan : l));
  });
  return { loan, summary };
}

function handleDelete(req: DemoRequest) {
  const id = Number(req.query.id);
  loanOrThrow(id);
  setState((s) => {
    s.loans = (s.loans ?? [])
      .filter((l) => l.id !== id)
      .map((l) => (l.sourceLoanId === id ? { ...l, sourceLoanId: null } : l));
  });
  return { ok: true };
}

function handleSimulate(req: DemoRequest) {
  const b = (req.body ?? {}) as Partial<LoanTermsInput>;
  if (!b.finalPeriod || typeof b.principal !== 'string') {
    throw new ApiError('invalid input', 400, { error: 'invalid input' });
  }
  const res = run({
    principal: b.principal,
    startDate: b.startDate ?? '',
    annualRate: b.annualRate ?? '',
    insuranceRate: b.insuranceRate ?? '0',
    insuranceBasis: b.insuranceBasis ?? 'initial',
    fees: b.fees ?? '0',
    periods: b.periods ?? [],
    finalPeriod: b.finalPeriod,
    earlyRepayments: b.earlyRepayments ?? [],
  });
  if (!res.ok) invalid(res.errors);
  return { schedule: res.schedule, summary: res.summary, warnings: res.warnings };
}

export function registerLoansHandlers(): void {
  registerHandler('GET', '/api/loans', handleList);
  registerHandler('POST', '/api/loans/simulate', handleSimulate);
  registerHandler('POST', '/api/loans', handleCreate);
  registerHandler('GET', '/api/loans/:id', handleGet);
  registerHandler('PUT', '/api/loans/:id', handleUpdate);
  registerHandler('DELETE', '/api/loans/:id', handleDelete);
}
```

```ts
import type { LoanListItem } from '../../api/loans';

export type LoansTab = 'loans' | 'simulations';

// Loans of one tab, repaid ones last, creation order otherwise.
export function sortLoans(all: LoanListItem[], tab: LoansTab): LoanListItem[] {
  const repaid = (l: LoanListItem) => (l.summary?.today.status === 'repaid' ? 1 : 0);
  return all
    .filter((l) => l.isSimulation === (tab === 'simulations'))
    .sort((a, b) => repaid(a) - repaid(b) || a.createdAt.localeCompare(b.createdAt) || a.id - b.id);
}
```

```tsx
import { useState } from 'react';
import { useQuery } from '@tanstack/react-query';
import { useTranslation } from 'react-i18next';
import { useSearchParams } from 'react-router-dom';
import { listLoans } from '../../api/loans';
import { EmptyState, ErrorState, LoadingBlock } from '../../components/StateBlocks';
import { LoanCard } from './LoanCard';
import { sortLoans, type LoansTab } from './loan-list';

const TABS: LoansTab[] = ['loans', 'simulations'];

export function Loans() {
  const { t } = useTranslation('loans');
  const [params, setParams] = useSearchParams();
  const tab: LoansTab = params.get('tab') === 'simulations' ? 'simulations' : 'loans';
  const [openId, setOpenId] = useState<number | null>(null);
  const q = useQuery({ queryKey: ['loans', 'list'], queryFn: listLoans });
  const shown = sortLoans(q.data?.loans ?? [], tab);

  const selectTab = (next: LoansTab) => {
    if (next === 'simulations') params.set('tab', 'simulations');
    else params.delete('tab');
    setParams(params, { replace: true });
  };

  return (
    <div className="p-4 md:p-6 max-w-6xl mx-auto">
      <header className="mb-4 flex flex-wrap items-end justify-between gap-3">
        <div>
          <h1 className="display text-xl text-ink-100">{t('title')}</h1>
          <p className="text-xs text-ink-500 mt-1">{t('subtitle')}</p>
        </div>
      </header>

      <div role="tablist" aria-label={t('title')} className="mb-4 flex gap-1">
        {TABS.map((k) => (
          <button
            key={k}
            type="button"
            role="tab"
            aria-selected={tab === k}
            onClick={() => selectTab(k)}
            className={`px-3 py-1.5 text-xs rounded ${tab === k ? 'bg-ink-800 text-ink-100' : 'text-ink-500 hover:text-ink-100'}`}
          >
            {t(`tabs.${k}`)}
          </button>
        ))}
      </div>

      {q.isError ? (
        <ErrorState error={q.error} onRetry={() => q.refetch()} />
      ) : q.isLoading ? (
        <LoadingBlock />
      ) : shown.length === 0 ? (
        <EmptyState title={t(`empty.${tab}.title`)} hint={t(`empty.${tab}.hint`)} />
      ) : (
        <div className="grid gap-3 md:grid-cols-2 lg:grid-cols-3">
          {shown.map((l) => (
            <LoanCard key={l.id} loan={l} onOpen={setOpenId} />
          ))}
        </div>
      )}
      {openId !== null && <span hidden data-open-loan={openId} />}
    </div>
  );
}
```

```ts
import type { LoanScheduleRow } from '../../api/loans';

export interface ChartGeometry {
  area: string; // closed path under the curve
  line: string; // the curve itself
  todayX: number | null; // null before the first / after the last instalment
  boundaries: number[]; // x of each period change
  early: Array<{ x: number; y: number }>; // early repayment markers
}

// Point 0 is the principal before any instalment; point i is the capital
// owed after instalment i. y grows downward (SVG), 0 € sits on the bottom.
export function chartGeometry(
  rows: LoanScheduleRow[],
  principal: string,
  asOf: string,
  w: number,
  h: number,
): ChartGeometry {
  const values = [Number(principal), ...rows.map((r) => Number(r.balance))];
  const max = Math.max(...values, 1);
  const n = Math.max(values.length - 1, 1);
  const x = (i: number) => (i / n) * w;
  const y = (v: number) => h - (v / max) * h;
  const line = `M${values.map((v, i) => `${x(i).toFixed(1)},${y(v).toFixed(1)}`).join(' L')}`;
  const paid = rows.filter((r) => r.date <= asOf).length;
  return {
    line,
    area: `${line} L${x(n).toFixed(1)},${h} L0,${h} Z`,
    todayX: paid > 0 && paid < rows.length ? x(paid) : null,
    boundaries: rows.flatMap((r, i) => (i > 0 && r.periodIndex !== rows[i - 1]!.periodIndex ? [x(i)] : [])),
    early: rows.flatMap((r, i) => (r.earlyRepayment ? [{ x: x(i + 1), y: y(Number(r.balance)) }] : [])),
  };
}
```

```ts
import type { LoanScheduleRow } from '../../api/loans';

export interface TimelineItem {
  periodIndex: number; // -1 = final period
  kind: LoanScheduleRow['kind'];
  from: string;
  to: string;
  months: number;
  payment: string; // first instalment of the period
  rate: string;
  varies: boolean; // payment changes inside the period (reduce_payment repayment)
}

// One item per run of rows sharing a period. The loan's very last
// instalment absorbs rounding, so it never counts as a change.
export function timelineItems(rows: LoanScheduleRow[]): TimelineItem[] {
  const items: TimelineItem[] = [];
  rows.forEach((r, i) => {
    const cur = items[items.length - 1];
    if (cur && cur.periodIndex === r.periodIndex) {
      cur.to = r.date;
      cur.months += 1;
      if (i < rows.length - 1 && r.payment !== cur.payment) cur.varies = true;
      return;
    }
    items.push({
      periodIndex: r.periodIndex, kind: r.kind, from: r.date, to: r.date,
      months: 1, payment: r.payment, rate: r.rate, varies: false,
    });
  });
  return items;
}
```

```ts
import type { LoanScheduleRow } from '../../api/loans';

export interface YearGroup {
  year: string;
  rows: LoanScheduleRow[];
  totals: { payment: string; interest: string; capital: string; insurance: string };
}

const cents = (s: string) => Math.round(Number(s) * 100);
const money = (c: number) => (c / 100).toFixed(2);

// Calendar-year buckets with totals summed in cents (no float drift).
export function groupByYear(rows: LoanScheduleRow[]): YearGroup[] {
  const groups: Array<{ year: string; rows: LoanScheduleRow[] }> = [];
  for (const r of rows) {
    const year = r.date.slice(0, 4);
    const last = groups[groups.length - 1];
    if (last && last.year === year) last.rows.push(r);
    else groups.push({ year, rows: [r] });
  }
  return groups.map((g) => {
    const sum = (k: 'payment' | 'interest' | 'capital' | 'insurance') =>
      money(g.rows.reduce((s, r) => s + cents(r[k]), 0));
    return {
      ...g,
      totals: { payment: sum('payment'), interest: sum('interest'), capital: sum('capital'), insurance: sum('insurance') },
    };
  });
}
```

```tsx
    ['actions.changePayment', onChangePayment],
    ['actions.whatIf', onWhatIf],
```

```ts
  LoanEarlyRepayment,
  LoanFinalPeriod,

} from '../../../api/loans';
import { parseDecimal } from '../../../lib/format';

// Editor state: every input kept as the user typed it (French decimals,
// spaces), parsed only when building the request.
export interface PeriodForm {
  kind: LoanFixedPeriodKind;
  months: string;
  amount: string;
  rate: string; // '' = use the loan rate
}

export interface EarlyForm {
  date: string; // YYYY-MM
  amount: string;
  effect: LoanRepaymentEffect;
  penalty: string;
}

export interface LoanForm {
  name: string;
  kind: LoanKind;
  isSimulation: boolean;
  sourceLoanId: number | null;
  currency: string;
  principal: string;
  startDate: string; // YYYY-MM-DD
  annualRate: string;
  insuranceRate: string;
  insuranceBasis: LoanInsuranceBasis;
  fees: string;
  periods: PeriodForm[];
  solve: 'payment' | 'end_date';
  endDate: string; // YYYY-MM, used when solve === 'payment'
  finalAmount: string; // used when solve === 'end_date'
  finalRate: string;
  earlyRepayments: EarlyForm[];
}

// Dotted engine field path ("periods.0.amount") → i18n key in `loans`.
export type FieldErrors = Record<string, string>;

const YEAR_MONTH = /^\d{4}-(0[1-9]|1[0-2])$/;
const ISO_DATE = /^\d{4}-(0[1-9]|1[0-2])-(0[1-9]|[12]\d|3[01])$/;

// Like parseDecimal, but rates allow 4 fraction digits (insurance 0,345 %)
// and a trailing %; capped at 100.
export function parseRate(raw: string): string | null {
  const cleaned = raw.replace(/%/g, '').replace(/\s+/g, '').replace(',', '.').trim();
  if (!/^\d+(\.\d{1,4})?$/.test(cleaned) || Number(cleaned) > 100) return null;
  return cleaned;
}

export function emptyForm(isSimulation: boolean, today: string): LoanForm {
  return {
    name: '', kind: 'mortgage', isSimulation, sourceLoanId: null, currency: 'EUR',
    principal: '', startDate: today, annualRate: '', insuranceRate: '0', insuranceBasis: 'initial', fees: '0',
    periods: [], solve: 'payment', endDate: '', finalAmount: '', finalRate: '', earlyRepayments: [],
  };
}

export function formFromLoan(l: LoanInput): LoanForm {
  const fp = l.finalPeriod;
  return {
    name: l.name, kind: l.kind, isSimulation: l.isSimulation, sourceLoanId: l.sourceLoanId, currency: l.currency,
    principal: l.principal, startDate: l.startDate, annualRate: l.annualRate, insuranceRate: l.insuranceRate,
    insuranceBasis: l.insuranceBasis, fees: l.fees,
    periods: l.periods.map((p) => ({ kind: p.kind, months: String(p.months), amount: p.amount ?? '', rate: p.rate ?? '' })),
    solve: fp.solve,
    endDate: fp.solve === 'payment' ? fp.endDate : '',
    finalAmount: fp.solve === 'end_date' ? fp.amount : '',
    finalRate: fp.rate ?? '',
    earlyRepayments: l.earlyRepayments.map((e) => ({ date: e.date, amount: e.amount, effect: e.effect, penalty: e.penalty ?? '' })),
  };
}

// A simulation always points at a REAL loan: duplicating a simulation keeps
// its source rather than chaining scenario → scenario.
export function asSimulation(
  f: LoanForm,
  source: { id: number; isSimulation: boolean; sourceLoanId: number | null },
  name: string,
): LoanForm {
  return { ...f, name, isSimulation: true, sourceLoanId: source.isSimulation ? source.sourceLoanId : source.id };
}

export function formToTerms(f: LoanForm): { terms: LoanTermsInput } | { fieldErrors: FieldErrors } {
  const errors: FieldErrors = {};
  const money = (raw: string, field: string): string => {
    const v = parseDecimal(raw);
    if (v === null || v.startsWith('-')) {
      errors[field] = 'form.invalidDecimal';
      return '0';
    }
    return v;
  };
  const rate = (raw: string, field: string): string => {
    const v = parseRate(raw);
    if (v === null) {
      errors[field] = 'form.invalidRate';
      return '0';
    }
    return v;
  };
  const optional = <T,>(raw: string, parse: (raw: string) => T): T | undefined =>
    raw.trim() === '' ? undefined : parse(raw);
  const month = (raw: string, field: string): string => {
    if (!YEAR_MONTH.test(raw)) errors[field] = 'form.invalidMonth';
    return raw;
  };

  if (!ISO_DATE.test(f.startDate)) errors.startDate = 'form.invalidDate';
  const principal = money(f.principal, 'principal');
  const annualRate = rate(f.annualRate, 'annualRate');
  const insuranceRate = optional(f.insuranceRate, (r) => rate(r, 'insuranceRate')) ?? '0';
  const fees = optional(f.fees, (r) => money(r, 'fees')) ?? '0';

  const periods = f.periods.map((p, i): LoanFixedPeriod => {
    const months = Number(p.months);
    if (!Number.isInteger(months) || months < 1) errors[`periods.${i}.months`] = 'form.invalidMonths';
    const out: LoanFixedPeriod = { kind: p.kind, months };
    if (p.kind === 'payment') out.amount = money(p.amount, `periods.${i}.amount`);
    const r = optional(p.rate, (raw) => rate(raw, `periods.${i}.rate`));
    if (r !== undefined) out.rate = r;
    return out;
  });

  const finalRate = optional(f.finalRate, (raw) => rate(raw, 'finalPeriod.rate'));
  const withRate = finalRate === undefined ? {} : { rate: finalRate };
  const finalPeriod: LoanFinalPeriod = f.solve === 'payment'
    ? { solve: 'payment', endDate: month(f.endDate, 'finalPeriod.endDate'), ...withRate }
    : { solve: 'end_date', amount: money(f.finalAmount, 'finalPeriod.amount'), ...withRate };

  const earlyRepayments = f.earlyRepayments.map((e, i): LoanEarlyRepayment => {
    const out: LoanEarlyRepayment = {
      date: month(e.date, `earlyRepayments.${i}.date`),
      amount: money(e.amount, `earlyRepayments.${i}.amount`),
      effect: e.effect,
    };
    const penalty = optional(e.penalty, (raw) => money(raw, `earlyRepayments.${i}.penalty`));
    if (penalty !== undefined) out.penalty = penalty;
    return out;
  });

  if (Object.keys(errors).length > 0) return { fieldErrors: errors };
  return {
    terms: {
      principal, startDate: f.startDate, annualRate, insuranceRate, insuranceBasis: f.insuranceBasis, fees,
      periods, finalPeriod, earlyRepayments,
    },
  };
}

export function formToInput(f: LoanForm): { input: LoanInput } | { fieldErrors: FieldErrors } {
  const res = formToTerms(f);
  const nameError: FieldErrors = f.name.trim() === '' ? { name: 'form.nameRequired' } : {};
  if ('fieldErrors' in res) return { fieldErrors: { ...res.fieldErrors, ...nameError } };
  if (nameError.name) return { fieldErrors: nameError };
  return {
    input: {
      ...res.terms,
      name: f.name.trim(), kind: f.kind, isSimulation: f.isSimulation,
      sourceLoanId: f.sourceLoanId, currency: f.currency,
    },
  };
}

// Engine issues (422 errors, warnings) keyed by field; issues without a
// field land under '' and are shown by PreviewSummary.
export function issuesToFieldErrors(issues: LoanIssue[]): FieldErrors {
  const out: FieldErrors = {};
  for (const i of issues) out[i.field ?? ''] = `issues.${i.code}`;
  return out;
}
```

```ts
import { useEffect, useState } from 'react';
import { useQuery } from '@tanstack/react-query';
import { loanIssues, simulateLoan, type LoanIssue, type LoanTermsInput } from '../../../api/loans';

// Debounced live preview through POST /api/loans/simulate. `terms` null
// (form not parseable yet) keeps the last result on screen.
export function useLoanPreview(terms: LoanTermsInput | null, delayMs = 250) {
  const key = terms ? JSON.stringify(terms) : null;
  const [debounced, setDebounced] = useState(key);
  useEffect(() => {
    const h = setTimeout(() => setDebounced(key), delayMs);
    return () => clearTimeout(h);
  }, [key, delayMs]);
  const q = useQuery({
    queryKey: ['loans', 'simulate', debounced],
    queryFn: () => simulateLoan(JSON.parse(debounced!) as LoanTermsInput),
    enabled: debounced !== null,
    retry: false,
    placeholderData: (prev) => prev,
  });
  const issues: LoanIssue[] = q.isError ? (loanIssues(q.error) ?? []) : [];
  return {
    data: q.isError ? undefined : q.data,
    issues,
    pending: key !== debounced || q.isFetching,
    failed: q.isError && loanIssues(q.error) === null,
  };
}
```

```tsx
import { useMemo, useState, type FormEvent } from 'react';
import { useMutation, useQueryClient } from '@tanstack/react-query';
import { useTranslation } from 'react-i18next';
import { createLoan, loanIssues, updateLoan, type Loan, type LoanInput } from '../../../api/loans';
import { ApiError } from '../../../api/apiError';
import { BasicsFields } from './BasicsFields';
import { PeriodsFields } from './PeriodsFields';
import { FinalPeriodFields } from './FinalPeriodFields';
import { EarlyRepaymentsFields } from './EarlyRepaymentsFields';
import { PreviewSummary } from './PreviewSummary';
import { useLoanPreview } from './useLoanPreview';
import { formToInput, formToTerms, issuesToFieldErrors, type FieldErrors, type LoanForm } from './form-state';

interface Props {
  title: string;
  initial: LoanForm;
  loanId: number | null; // null = create
  onClose: () => void;
  onSaved: (loan: Loan) => void;
}

export function LoanEditor({ title, initial, loanId, onClose, onSaved }: Props) {
  const { t } = useTranslation('loans');
  const qc = useQueryClient();
  const [form, setForm] = useState<LoanForm>(initial);
  const [submitted, setSubmitted] = useState(false);
  const [serverError, setServerError] = useState<string | null>(null);
  const parsed = useMemo(() => formToTerms(form), [form]);
  const preview = useLoanPreview('terms' in parsed ? parsed.terms : null);

  // Parse errors appear after the first submit attempt; engine errors from
  // the live preview appear as soon as the server reports them.
  const local = submitted ? formToInput(form) : null;
  const errors: FieldErrors = {
    ...(local && 'fieldErrors' in local ? local.fieldErrors : {}),
    ...issuesToFieldErrors(preview.issues),
  };

  const save = useMutation({
    mutationFn: (input: LoanInput) => (loanId === null ? createLoan(input) : updateLoan(loanId, input)),
    onSuccess: async ({ loan }) => {
      await qc.invalidateQueries({ queryKey: ['loans'] });
      onSaved(loan);
    },
    onError: (err) => {
      if (err instanceof ApiError && err.status === 409) setServerError(t('form.nameTaken'));
      else if (loanIssues(err)) setServerError(t('form.fixErrors'));
      else setServerError(t('form.genericError'));
    },
  });

  const patch = (p: Partial<LoanForm>) => setForm((f) => ({ ...f, ...p }));
  const submit = (e: FormEvent) => {
    e.preventDefault();
    setSubmitted(true);
    setServerError(null);
    const res = formToInput(form);
    if ('input' in res) save.mutate(res.input);
  };

  return (
    <div
      role="dialog"
      aria-modal="true"
      aria-label={title}
      className="fixed inset-0 z-50 bg-black/50 flex items-start justify-center p-4 overflow-y-auto"
      onClick={onClose}
    >
      <form noValidate onSubmit={submit} onClick={(e) => e.stopPropagation()} className="surface p-4 w-full max-w-3xl space-y-5 my-8">
        <h2 className="display text-sm text-ink-100">{title}</h2>
        <BasicsFields form={form} onChange={patch} errors={errors} />
        <PeriodsFields periods={form.periods} onChange={(periods) => patch({ periods })} errors={errors} />
        <FinalPeriodFields form={form} onChange={patch} errors={errors} summary={preview.data?.summary} />
        <EarlyRepaymentsFields items={form.earlyRepayments} onChange={(earlyRepayments) => patch({ earlyRepayments })} errors={errors} />
        <PreviewSummary preview={preview.data} pending={preview.pending} failed={preview.failed} issues={preview.issues} currency={form.currency} />
        {serverError && <div role="alert" className="text-xs text-clay-300">{serverError}</div>}
        <div className="flex justify-end gap-2">
          <button type="button" className="btn-secondary" onClick={onClose}>{t('actions.cancel')}</button>
          <button type="submit" className="btn-primary" disabled={save.isPending}>{t('actions.save')}</button>
        </div>
      </form>
    </div>
  );
}
```

```ts
import type {
  LoanEarlyRepayment,
  LoanFinalPeriod,
  LoanFixedPeriod,
  LoanScheduleRow,
  LoanTermsInput,
} from '../../api/loans';

export type PaymentChange = { kind: 'amount'; amount: string } | { kind: 'rate'; rate: string };

// "From month X my payment (or rate) changes." Instalments before X become
// fixed history that reproduces exactly what was paid; a new final period
// starts at X — amount fixed → end date floats, rate change → end date kept.
// Returns null unless X is a month of the schedule after the first one.
export function splitAtDate(
  terms: LoanTermsInput,
  schedule: LoanScheduleRow[],
  fromMonth: string,
  change: PaymentChange,
): LoanTermsInput | null {
  const at = schedule.findIndex((r) => r.date.slice(0, 7) === fromMonth);
  const rowAt = schedule[at];
  const lastRow = schedule[schedule.length - 1];
  if (at <= 0 || !rowAt || !lastRow) return null;

  const periods: LoanFixedPeriod[] = [];
  for (const r of schedule.slice(0, at)) {
    const kind = r.kind === 'final' ? 'payment' : r.kind;
    const amount = kind === 'payment' ? r.payment : undefined;
    const rate = r.rate === terms.annualRate ? undefined : r.rate;
    const last = periods[periods.length - 1];
    if (last && last.kind === kind && last.amount === amount && last.rate === rate) {
      last.months += 1;
      continue;
    }
    periods.push({
      kind, months: 1,
      ...(amount !== undefined ? { amount } : {}),
      ...(rate !== undefined ? { rate } : {}),
    });
  }

  const rateInForce = rowAt.rate === terms.annualRate ? {} : { rate: rowAt.rate };
  const finalPeriod: LoanFinalPeriod = change.kind === 'amount'
    ? { solve: 'end_date', amount: change.amount, ...rateInForce }
    : { solve: 'payment', endDate: lastRow.date.slice(0, 7), rate: change.rate };

  // Repayments before X now sit in fixed history. Give them the new final
  // period's neutral effect so the engine's "latest effect decides" rule
  // can't override what the user just asked for.
  const neutral = change.kind === 'amount' ? 'shorten' : 'reduce_payment';
  const earlyRepayments: LoanEarlyRepayment[] = terms.earlyRepayments.map((e) =>
    (e.date < fromMonth ? { ...e, effect: neutral } : e));

  return { ...terms, periods, finalPeriod, earlyRepayments };
}
```

```ts
import type { LoanSummary } from '../../../api/loans';

export interface Comparison {
  endMonthsDelta: number; // negative = ends earlier
  costDelta: string; // negative = cheaper
  monthlyDelta: string;
}

const cents = (s: string) => Math.round(Number(s) * 100);
const money = (c: number) => (c / 100).toFixed(2);
const monthIndex = (iso: string) => Number(iso.slice(0, 4)) * 12 + Number(iso.slice(5, 7)) - 1;

export function compareSummaries(base: LoanSummary, next: LoanSummary): Comparison {
  return {
    endMonthsDelta: monthIndex(next.endDate) - monthIndex(base.endDate),
    costDelta: money(cents(next.totals.cost) - cents(base.totals.cost)),
    monthlyDelta: money(cents(next.currentPaymentWithInsurance) - cents(base.currentPaymentWithInsurance)),
  };
}
```

```tsx
                className={`px-2 py-1 text-xs rounded ${lever === k ? 'bg-ink-800 text-ink-100' : 'text-ink-500'}`}>
```

```markdown
# Loans

Follow every loan you're repaying — mortgage, car, consumer credit — and
see, at any time, **how much capital you still owe**, **when the loan
ends** and **what it really costs**: interest + insurance + fees +
early-repayment penalties.

Loans live on their own page (**Loans** in the sidebar). They don't touch
your accounts or transactions.

## Create a loan

**New loan** asks for:

- **Amount borrowed**, **first instalment** date, **interest rate** (% per
  year, nominal — the rate on your loan offer).
- **Insurance rate** (% per year; `0` for most consumer loans) and whether
  your insurer charges it on the **initial capital** (same amount every
  month) or on the **capital owed** (decreasing).
- **One-off fees**: application fee, guarantee, broker.

Then the **timeline**:

- **Periods before the last one** — optional. Each is a number of months
  and a kind:
  - *Payment*: you pay a fixed monthly amount (e.g. a reduced first
    phase).
  - *Partial deferral*: you pay only the interest (and insurance); the
    capital doesn't move — typical while a house is being built.
  - *Total deferral*: you pay nothing but insurance; the interest is added
    to the capital owed.
  - Each period can have its own rate (variable rate, renegotiation).
- **Last period** — Athena computes what you don't know:
  - *I know the end date* → it computes the monthly payment;
  - *I know the monthly amount* → it computes the end date.
- **Early repayments** — a lump sum on a month, which either **lowers the
  payment** (end date kept) or **shortens the loan** (payment kept), plus
  the penalty your bank charges.

The preview updates as you type. Amounts accept French or English
formatting (`245 000`, `3,85`).

## Read a loan

Open a card to see capital owed today, the share already repaid, interest
paid so far, months left, the total cost broken down, a chart of the
capital owed, the list of periods and the full schedule grouped by year.
An instalment counts as paid once its date has passed.

**Change payment from…** handles "from March my payment goes up to
1 400 €": earlier instalments are kept as they were and the end date is
recomputed.

## What-if and simulations

**What-if** lets you try an early repayment, a new payment or a new rate
and compares the result with the current loan (end date, monthly payment,
total cost, money saved). Then **Discard**, **Apply to loan**, or **Save as
simulation**.

Simulations live in the **Simulations** tab. One saved from a loan keeps
showing the comparison with that loan; if you delete the loan, the
simulation stays. **New simulation** also works for a loan you don't have
yet.

## How the numbers are computed

- Monthly rate = annual rate ÷ 12; interest and insurance are rounded to
  the cent each month; the last instalment absorbs the remaining cents, so
  the capital owed always ends at exactly 0.
- Monthly instalments only; up to 50 years.
- The effective rate (TAEG) is not computed.
```

```markdown
# Prêts

Suivez chaque prêt que vous remboursez — immobilier, auto, crédit à la
consommation — et voyez à tout moment **le capital restant dû**, **la date
de fin** et **ce qu'il coûte vraiment** : intérêts + assurance + frais +

Les prêts ont leur propre page (**Prêts** dans le menu). Ils ne modifient

## Créer un prêt

**Nouveau prêt** demande :

- le **montant emprunté**, la date de **première échéance**, le **taux
  d'intérêt** (% par an, nominal — celui de votre offre de prêt) ;
- le **taux d'assurance** (% par an ; `0` pour la plupart des crédits à la
  consommation) et s'il s'applique au **capital initial** (même montant
  chaque mois) ou au **capital restant dû** (dégressif) ;
- les **frais** : dossier, garantie, courtage.

Puis l'**échéancier** :

- **Périodes avant la dernière** — facultatives. Chacune a un nombre de
  mois et un type :
  - *Échéance* : vous payez une mensualité fixe (ex. un palier réduit) ;
  - *Différé partiel* : vous ne payez que les intérêts (et l'assurance) ;
    le capital ne bouge pas — typique pendant une construction ;
  - *Différé total* : vous ne payez que l'assurance ; les intérêts
    s'ajoutent au capital restant dû ;
  - chaque période peut avoir son propre taux (taux variable,
    renégociation).
- **Dernière période** — Athena calcule ce que vous ne connaissez pas :
  - *Je connais la date de fin* → elle calcule la mensualité ;
  - *Je connais la mensualité* → elle calcule la date de fin.
- **Remboursements anticipés** — une somme versée un mois donné, qui
  **baisse la mensualité** (date de fin conservée) ou **raccourcit le
  prêt** (mensualité conservée), avec les indemnités facturées par la
  banque.

L'aperçu se met à jour pendant la saisie. Les montants acceptent
`245 000` comme `3,85`.

## Consulter un prêt

Ouvrez une carte : capital restant dû, part déjà remboursée, intérêts
payés, mois restants, coût total détaillé, courbe du capital restant dû,
liste des périodes et tableau d'amortissement par année. Une échéance
compte comme payée dès que sa date est passée.

**Changer la mensualité à partir de…** gère « à partir de mars je passe à
1 400 € » : les échéances précédentes restent telles quelles et la date de
fin est recalculée.

## « Et si… » et simulations

**Et si…** permet de tester un remboursement anticipé, une nouvelle
mensualité ou un nouveau taux, et compare le résultat au prêt actuel
(date de fin, mensualité, coût total, économie). Ensuite **Abandonner**,
**Appliquer au prêt** ou **Enregistrer comme simulation**.

Les simulations sont dans l'onglet **Simulations**. Une simulation issue
d'un prêt garde la comparaison avec ce prêt ; si vous supprimez le prêt,
la simulation reste. **Nouvelle simulation** fonctionne aussi pour un prêt
que vous n'avez pas encore.

## Comment les chiffres sont calculés

- Taux mensuel = taux annuel ÷ 12 ; intérêts et assurance sont arrondis au
  centime chaque mois ; la dernière échéance absorbe les centimes restants,
  le capital restant dû finit donc toujours à 0 exactement.
- Échéances mensuelles uniquement ; 50 ans maximum.
- Le TAEG n'est pas calculé.
```
